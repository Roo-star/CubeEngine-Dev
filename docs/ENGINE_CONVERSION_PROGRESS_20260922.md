# 转换引擎：本轮实现与验收边界

2026-09-22。单一开发目录 CubeEngine-SRTP，分支 SRTP。改动保持本地，未提交或推送；没有创建分支或项目副本，没有调用外部模型。

## 实际进入工作流的改动

1. `SourceWorkspace` 建立视觉证据目录。Python 绘制调用、字面颜色、字体/资源加载、JSON 配色形成带路径、位置和 SHA256 的事实。模型可引用事实 ID，由构建器解析原值并保留来源；源文件变化使旧引用失效。五类参考游戏均有观察数据。动态计算的外观仍需理解，不能冒充确定性提取结果。
2. Scene/Asset → Ursina 增加源 RGBA 轮廓挤出、帧动画、音频组件、HUD 原字体和背景。挤出保留透明洞与像素颜色，当前上限 16,384 像素，不偷偷缩图。动画只更新外观；音效通过 Rule 状态中的事件计数触发，调音量或普通刷新不会重播。几何、纹理和未变化碰撞体复用。
3. Workbench 默认异步编译；编译线程只发送事件，界面线程更新 UI。单任务保护、取消、源/尺寸/Intent 变化使旧结果失效。已发出的网络请求不能强制从服务端撤销，但取消被接受后不得发布结果。发布开始后取消不阻塞界面，也不谎报已取消。
4. 发布成功包时，原始资源按 Asset IR 声明打入 `resources/`，附资源索引，保持原 URI 和 IR 哈希。读取优先使用包内资源，损坏不回退到本机同名素材。旧包仍按原路径打开；不会自动改写历史包。
5. 右键旋转和游戏点击分开识别；必须没有拖动、起止指向同格才派发点击。增加 Reset view，恢复相机位置、角度、距离和镜头。Restart 按钮独立重开，R 键交回 Input IR。现有内部层选择保留。
6. Scene 投影保留规则状态不变校验；相同状态跳过重复投影。Ursina 仅刷新变更节点；更换可点击层时仍更新碰撞体。

## 已执行验证

全库 `python -m unittest discover -s tests`：**394 项，392 通过，1 跳过，1 环境错误**。

- 跳过项是真实 API 测试。
- 环境错误是旧 AlphaZero 测试从上级目录导入 `Coach`。实际训练工程在同级 `CubeEngine-AI-Dev`；加该路径后又缺 `tqdm`。未改写外部训练工程、未用 mock 掩盖这个失败，AI 对手集成仍未完成。
- 最后相机/键盘路由调整后，相关 34 项再次通过。
- 新任务测试覆盖重复提交、等待响应中取消、取消不写旧包、切换项目丢弃旧结果。
- 可移植测试通过正式发布函数、移动目录、删除原素材、ProjectHost 打开及物理输入；损坏资源时即使提供源目录也拒绝加载。
- 原源码独立基准：井字棋 50 组操作轨迹（含非法和终局操作），2048 的 256 种行，扫雷 12 个首击展开区域，Connect Four 100 个棋盘的双方获胜判断，Snake 100 次移动/增长。
- 这些算法基准不覆盖每款游戏全部状态机，也不是由真实 LLM 生成的完整游戏验收。

### 真实渲染检查

`python -m tests.ursina_scene_probe` 使用原有封存包，验证三维内层射线命中、不同坐标节点、悬停、输入/回放、重开后增量更新。原包没有被重写。

`python -m tests.ursina_visual_probe` 使用明确标识的内部素材测试数据，走真实 Asset/Scene 编译和 Ursina 几何渲染。检查原色网格挤出、动画前后实际像素颜色变化、音频加载。音频采用 null 输出，不把加载通过说成听感验收。

以上使用 Panda GraphicsBuffer，没有执行可见原生窗口人工游玩验收，也没有把测试数据放入 Source Library 冒充转换产物。

### 性能范围

`python -m tests.ursina_performance_probe`；同一机器，900×650 离屏窗口，12 次刷新，舍弃前 2 次后取中位数：

| 保存包 | 节点 | 启动 | 静态刷新＋渲染中位数 |
|---|---:|---:|---:|
| 3×3×3 参考包 | 28 | 0.056 s | 0.834 ms |
| 20×20×5 历史 LLM Target | 2002 | 3.962 s | 15.475 ms |

大包优化前约 237.969 ms，加入增量场景和相同状态缓存后降至上述结果。该大包没有可选碰撞体，不涵盖 2,000 个碰撞体的射线性能，也不证明其 Snake 玩法正确。连续状态变化、完整 HUD 和声音同时工作时仍需单独测量。
