# Pygame Minesweeper reference assembly

This directory assembles the published MIT-licensed wheels for:

- `pygame-minesweeper` 1.0.11
- `pygame-minesweeper-core` 1.0.18
- `pygame-minesweeper-sprites` 1.0.41
- `appdirs` 1.4.4

The three `minesweeper` namespace packages are merged exactly as Python would
install them. `run_game.py` only supplies the upstream CLI's documented
`basic` argument so CubeEngine can open a playable game with one Play action.

Upstream project: https://pypi.org/project/pygame-minesweeper/

The relevant licenses are preserved beside the source.
