# Complete Turtle Connect Four reference

This CubeEngine-maintained acceptance source is derived from the Apache-2.0
Free Python Games Connect exercise. The upstream exercise intentionally leaves
winner detection and full-row handling as TODOs; this variant completes those
items so SRTP Function 1 can prove and lift a real `CONNECT_N = 4` terminal
rule. It remains a standalone, playable Turtle source game.

Controls: click a column to drop a piece; press `R` to restart.

Upstream: https://github.com/grantjenks/free-python-games
