# Complete Tic Tac Toe source

This is a complete original two-player Pygame source game for the LLM compiler acceptance flow, not a rule-only sample and not a precompiled 3D adapter.

Entry: `main.py`. Requires Pygame. Click an empty cell to alternate X/O. Three in a row wins, a full board without a winner draws. Occupied cells and moves after game end are rejected. R restarts; Escape or closing the window quits.

Workbench: select **Tic Tac Toe · Complete Pygame source**, choose **Source 2D**, then **PLAY**. To evaluate actual conversion, compile this source, approve Source, then request a 3×3×3 no-gravity game preserving alternating X/O placement and winning on any straight three-cell line. Approve Target and choose **Transformed 3D → PLAY**.

The separately checked-in `artifacts/tictactoe_target` is an engineering reference bundle, not the output of compiling this new source. Do not use it as proof of LLM conversion fidelity.
